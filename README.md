# Presupuesto y Documento de Alcance

## Descripción del proyecto
Nombre de la aplicación: Impostor
Descripción: la aplicación consta de un juego de minimo 3 jugadores donde hay 1 impostor que tiene que intentar que no lo descubran y el resto que tienen que descubrir al impostor en el cual primero se tendrán que
loguear ( en el caso de no tener una cuenta la tendrán que crear ).
que aborda: Aborda el aburrimiento.
Público objetivo: tenemos de público a todos, es un juego simple y facil de entender que puede juntar a toda una familia
Objetivo general: los usuarios jugarán rondas, con luego una votacion hasta que descubran al impostor, en caso de que no se descubra el juego seguira hasta que queden 2 jugadores
Principales funciones: los usuarios se podrán loguearse por primera vez o usar una cuenta
ya hecha anteriormente. Una vez iniciado todo podrán entrar a una sala y se les asignara el rol y tema para la partida, la partida comenzara y tendran una palabra para decir y que el resto no piense que es el impostor.

## Alcance:
funcionalidades que se desarrollaran: se desarrollará una bd, pedidos HTTP, la
comunicación en tiempo real con WS

Principales características esperadas del producto final: Juego multijugador con turnos y chat en vivo
